# Api Notes

API REST para gerenciamento de usuários e notas, permitindo criação, edição, exclusão e organização de anotações.

## Getting Started

### Requirements

- Vscode
- Node
- Nest
- Prisma

### Installation

```bash
git clone https://github.com/code043/nest-notes.git
cd nest-notes
npm install
npm run dev
```
